# Smart Restaurant Billing & Order Management System

## Project Overview

Smart Restaurant Billing & Order Management System is a Python-based command-line application that helps restaurants manage customer orders, generate bills, apply discounts, calculate GST, and view daily sales reports.

The project is developed using basic Python concepts such as functions, loops, lists, dictionaries, modules, and conditional statements.

## Features

- Display restaurant menu
- Take customer orders
- Order multiple items
- Automatic bill generation
- Discount calculation
- GST calculation
- Daily sales report
- Revenue tracking
- Item sales tracking

## Technologies Used

- Python 3
- Functions
- Lists
- Dictionaries
- Loops
- Conditional Statements
- Modules

## How to Run

1. Open terminal
2. Navigate to project folder

```bash
cd Restaurant_Billing_System
```

3. Run the project

```bash
python main.py
```
