# Problem Statement

Many small restaurants and food stalls calculate bills manually, which can lead to errors in pricing, discounts, and tax calculations.

This project provides an automated solution for order management and bill generation using Python.

# Scope of the Project

The system allows restaurant staff to:

- Display menu items
- Accept customer orders
- Calculate bills automatically
- Apply discounts
- Calculate GST
- Generate sales reports

# Target Users

- Restaurants
- Food Stalls
- Cafeterias
- Small Cafes

# High Level Features

1. Menu Management
2. Customer Order Processing
3. Bill Generation
4. Discount Calculation
5. GST Calculation
6. Daily Sales Report
7. Revenue Tracking
